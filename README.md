# AI Medical Prescription Verification System

##  Description
This project is an AI-powered system designed to **verify medical prescriptions** and enhance patient safety.  
It intelligently analyzes drug data to prevent errors, misinterpretations, and potential drug interactions.  
The system provides a seamless way for medical professionals to input prescriptions and receive verified outputs.

##  Features
-  AI-driven prescription verification  
-  Drug data analysis using Hugging Face models  
-  Robust data validation with Pydantic  
-  Fast and scalable backend with FastAPI  
-  Simple and interactive UI with Streamlit  

##  Tech Stack
- **Backend:** FastAPI (Python)  
- **Frontend:** Streamlit (Python)  
- **AI Models:** Hugging Face  
- **Validation:** Pydantic
